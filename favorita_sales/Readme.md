# Ziel
Prognose von Verkaufszahlen auf Basis des Kaggle-Datensatzes „Store Sales – Time Series Forecasting"; Datenbereinigung und explorative Analyse mit pandas und NumPy, Visualisierung mit Matplotlib und seaborn.

# Modelle des Machine Learnings
Aufbau von scikit-learn-Pipelines (Imputation, One-Hot-Encoding) und Feature-Selektion; Vergleich von linearer Regression und Random Forest anhand von R², MAE und MSE; zusätzlich Erprobung von Clustering-Verfahren.

# Ergebnis
Die Prognosegüte war nicht aussagekräftig.
Der Schwerpunkt lag auf dem Kennenlernen der Methoden und der kritischen Bewertung der Ergebnisse.
