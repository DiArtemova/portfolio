# Analyse und Prognose von Verkaufsdaten aus Ecuador

## Projektziel
Prognose von Verkaufszahlen auf Basis des Kaggle-Datensatzes „Store Sales – Time Series Forecasting"; Datenbereinigung und explorative Analyse mit pandas und NumPy, Visualisierung mit Matplotlib und seaborn.

## Anfänglicher Projektumfang
Die erste Analyse konzentriert sich auf eine Filiale und ihre Warengruppen. Sobald der Workflow zuverlässig funktioniert, wird die Untersuchung auf weitere Filialen ausgeweitet.

## Geplantes Vorgehen
1. Originaldaten sichten und ihre Qualität überprüfen.
2. Zeitliche Muster und Unterschiede zwischen Warengruppen untersuchen.
3. Prognosehorizont und zeitliche Aufteilung der Daten festlegen.
4. Ein einfaches Referenzmodell erstellen.
5. Ein Machine-Learning-Modell mit dem Referenzmodell vergleichen.

# Modelle des Machine Learnings
Aufbau von scikit-learn-Pipelines (Imputation, One-Hot-Encoding) und Feature-Selektion; Vergleich von linearer Regression und Random Forest anhand von R², MAE und MSE; zusätzlich Erprobung von Clustering-Verfahren.
